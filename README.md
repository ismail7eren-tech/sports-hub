# 🏆 SportsHub

**SportsHub**, modern web teknolojileri ve yapay zeka algoritmaları kullanılarak
geliştirilmiş, yüz tanıma tabanlı kimlik doğrulama sistemine sahip bir spor platformudur.

Bu projede amaç; klasik kullanıcı adı–şifre yaklaşımının ötesine geçerek,
**biyometrik doğrulama** ile güvenli, hızlı ve yenilikçi bir kullanıcı deneyimi sunmaktır.
SportsHub, spor verilerine erişimi yalnızca **yetkilendirilmiş ve doğrulanmış**
kullanıcılara açan akıllı bir altyapı sunar.

---

## 🚀 Öne Çıkan Özellikler

- 🔐 Yapay zeka destekli yüz tanıma (DeepFace / VGG-Face)
- ⚛️ React + TypeScript ile geliştirilen modern ve akıcı arayüz
- 🐍 Python & Flask tabanlı güçlü backend mimarisi
- 📊 Spor takımları ve oyuncular için dinamik veri yapısı
- 🎨 Tailwind CSS ile sade, şık ve responsive tasarım
